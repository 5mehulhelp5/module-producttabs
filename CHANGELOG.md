All notable changes to this extension are documented here. The format

## [1.1.8] - 2026-10-07

### Changed
- Storefront colours follow the store palette on Hyva and Luma: tab bar and attribute label backgrounds #FAFAFA (were #F3F4F6 and #F9FAFB), borders #E5E5E5 (were #E5E7EB), panel and attribute value text #171717 (was #374151), paragraph and list text #525252 (was #4B5563) and tab hover text #171717.
